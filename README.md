# Optimizador de Corte de Vidrio

Sistema web para optimizar la distribución de piezas de vidrio sobre planchas y retazos reutilizables.

## Tecnologías

- React
- FastAPI
- Python
- PostgreSQL

## Arquitectura

- `frontend/`: interfaz web desarrollada con React.
- `backend/`: API REST y motor de optimización desarrollado con FastAPI y Python.

## Optimización

El sistema utilizará geometría rasterizada para ejecutar y comparar:

- First Fit
- Best Fit
- Worst Fit
