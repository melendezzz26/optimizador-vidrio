# Investigaciones técnicas

Usar un documento `SP-<ID>-<tema>.md` para una investigación con una pregunta
concreta, hipótesis, método, límites, resultados observados y conclusión.
Una propuesta o hipótesis no debe presentarse como un resultado validado.

Los scripts y entradas de rasterización pertenecen a
[`experiments/raster/`](../../experiments/raster/README.md). Guardar la evidencia
seleccionada en `docs/evidence/sprint-01/<ID>/` y enlazarla desde el informe.

Si una conclusión motiva una decisión arquitectónica, registrarla mediante un
ADR en `docs/adr/`. Este directorio todavía no contiene informes de investigación.
