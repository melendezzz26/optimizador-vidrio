# Documentación de interfaz y experiencia de usuario

Ubicación para flujos, estados de pantalla y criterios de interacción vinculados
a una SPEC. Cada documento debe identificar la funcionalidad, las entradas,
validaciones, estados vacíos o de error y criterios de aceptación relevantes.

Distinguir propuestas de diseño de comportamiento ya implementado. Enlazar los
artefactos fuente o la evidencia disponible, sin declarar validaciones inexistentes.

El código nuevo de interfaz se organiza en `frontend/src/features/`; la política
temporal del código actual se describe en [CONTRIBUTING.md](../../CONTRIBUTING.md).
