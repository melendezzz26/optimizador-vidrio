# Código compartido del frontend

Reservar este espacio para componentes visuales y utilidades utilizados por
varias features y sin reglas particulares de una funcionalidad.

No colocar aquí pantallas completas, flujos de autenticación, formularios propios
de pedidos, reglas de inventario ni código experimental. No crear abstracciones
anticipadas para llenar la carpeta ni mover componentes existentes en esta fase.

La organización por features se describe en
[CONTRIBUTING.md](../../../CONTRIBUTING.md).
